# 选十 · 极简共同选片原型

## 本地启动

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173`。编码代理开始工作前请先读 [`AGENTS.md`](./AGENTS.md)。

## 第一版只解决一个场景

杨可若上传某个体育馆约 100 张已经初筛、调色完成的照片，先邀请玄总，也可按需要继续添加其他选片人。每个人独立打 1 至 5 星，提交前互相看不到评分；全部提交后，系统按平均分排序，但不自动决定结果。所有选片人共同用独立的“终选”标记，确定恰好 10 张进入展览陈设。

## 三个页面

1. **创建**：选片标题、默认两位选片人、按需继续添加、批量上传照片。
2. **独立评分**：原比例网格、全屏看图、1 至 5 星、可选的一句话个人备注、数字键评分、评分进度、提交锁定。
3. **终选十张**：综合排序、显示三人分数与备注、独立“终选”标记、严格限制 10 张、确认后复制文件名。

## 明确不做

AI、评论讨论串、复杂账号、多轮评审、策展排版、公开投稿、授权管理、儿童身份信息、评分维度、自动决定最终结果。

## 原型说明

这是前端交互原型，数据只存在当前浏览器页面中，刷新后重置。页面中的“原型快捷方式”只用于快速预览三人评分完成后的终选状态，不属于正式产品功能。演示图片来自杨可若公开摄影网站。
